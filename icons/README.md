# App icon

A pawn, and the king in its shadow — the king it can become. `kingcoach.svg`
is the source; the PNGs are rendered from it (256 for the desktop launcher,
64 / 48 for the window, 34 for the sidebar) and `kingcoach.ico` is for the
Windows build.

The pawn is from the "cburnett" chess set by
[Colin M.L. Burnett](https://en.wikipedia.org/wiki/User:Cburnett), licensed
[GPLv2+](https://www.gnu.org/licenses/gpl-2.0.txt) — as in `pieces/`.
